用途標籤

收藏

備份匯出／匯入

匯出包含你的筆記、手動標籤、最愛、狀態，以及每筆收藏的目標（不含 token）。匯入時以較新的編輯為準，收藏庫裡沒有的項目可以重新排入分析。

連結收藏庫

只需要設定一次。token 只存在這個瀏覽器，只會送到 GitHub（api.github.com），不會出現在網址或紀錄裡。

使用 GitHub 登入

只選你的私人收藏庫，權限 Contents: Read and write。想看到「分析中」，可再加 Actions: Read-only（選用）。

收進 Collective Hub

拖到書籤列。在 GitHub 頁面按一下直接收藏；在 Threads 等其他網站，先選取貼文文字再按，會帶著文字開啟並要你確認。

iPhone／iPad 怎麼收藏？

iOS 不支援網頁加入分享選單。可以在 Threads 按「分享 → 拷貝連結」或複製貼文文字，回到這個網頁按「新增收藏」貼上；或用「捷徑」App 開啟 這個網址#text=（分享內容），開啟後一樣要你確認才收。
